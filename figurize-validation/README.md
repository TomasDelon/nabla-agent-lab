# Figurize Manim validation gallery

This directory renders the first executable visual foundation of Figurize with **Manim Community v0.20.1**.

## Purpose

The gallery validates two things separately:

1. reusable components, such as axes, semantic ticks, points, vectors, labels, intervals, angle codes and regions;
2. useful compositions, such as function evaluation, roots with horizontal tangents, geometry annotations, probability regions, linear transformations and tangent planes.

No raster image is edited or generated by an image model. Every PNG and video in the workflow artifact is rendered from the Python Manim source in this directory.

## Rendering locally

```bash
docker run --rm \
  --user root \
  -v "$PWD:/manim" \
  -w /manim/figurize-validation \
  manimcommunity/manim:v0.20.1 \
  bash render_gallery.sh
```

The results are written to `figurize-validation/output/`.

## Output contract

- `output/static/*.png`: final-frame previews on the Figurize default preview background
- `output/transparent/*.png`: selected scenes rendered with alpha transparency
- `output/video/*.mp4`: original Manim animations
- `output/gif/*.gif`: chat-friendly derivatives produced from the Manim MP4s
- `output/manifest.json`: hashes and output counts
- `output/logs/*.log`: one render log per scene
